Phase Focus Evidence work Capital boundary Decision
1 · Setup Engine foundation Full backtesting/research engine: data pipeline, strategy rules, cost model, reports, versioned code aur reproducible outputs. No live-test capital deployed. Ready / Not ready
2 · Paper evidence Capacity + stability proof Regime/instrument stress-tests, data-gap and assumption log, paper results, exceptions aur capacity evidence. Review record freeze before live testing. Continue / Pause / Reject
3 · Controlled validation Controlled live validation Written allocation, small controlled exposure, complete trade ledger, cost/slippage records, reconciliation aur weekly review. Only then ₹1,00,000 capped validation capital; no return target, guarantee ya automatic scaling. Validate / Pause / Reject
